Access passcode

The passcode is shared with the Studio Admin and works on every device. Saving a new one needs your GitHub token so it can be written to the shared file. There is no reset link on the lock screen — if you ever lose the passcode, use tools/reset_passcode.py locally.

How publishing works

  • The admin writes data/links.json straight to GitHub through the API.
  • The commit triggers the “Deploy to GitHub Pages” workflow, so the live page updates within a minute.
  • Nothing needs to be uploaded by hand.
